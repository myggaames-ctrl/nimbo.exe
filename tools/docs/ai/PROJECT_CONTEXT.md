# NIMBO AI
# PROJECT CONTEXT
Versión: 1.0

===============================================================================
¿QUÉ ES NIMBO?
===============================================================================

Nimbo AI es una plataforma inteligente de administración empresarial.

Su objetivo es convertirse en el asistente principal de cualquier empresa.

Nimbo combina:

• ERP

• Inteligencia Artificial

• Automatización

• Análisis de datos

• Gestión empresarial

Todo mediante conversación natural.

===============================================================================
EMPRESA ACTUAL
===============================================================================

Actualmente Nimbo está siendo desarrollado para la empresa:

Mi Cocina

Mi Cocina vende:

Electrodomésticos.

Repuestos.

Accesorios de cocina.

También administra reparaciones de licuadoras y pequeños electrodomésticos.

Toda decisión de desarrollo debe beneficiar primero a Mi Cocina.

Posteriormente el sistema será adaptable a cualquier empresa.

===============================================================================
FUENTE DE DATOS
===============================================================================

La fuente principal del inventario es:

Aronium POS

Nimbo NO debe duplicar el inventario.

Siempre debe consultar Aronium.

La información creada por Nimbo se almacena en su propia base de datos.

===============================================================================
OBJETIVO DEL MVP
===============================================================================

El MVP debe permitir administrar completamente Mi Cocina.

Debe incluir:

Clientes

Inventario

Presupuestos

Ventas

Servicio Técnico

Reportes

Configuración

Todo mediante conversación natural.

===============================================================================
VISIÓN FUTURA
===============================================================================

Después del MVP Nimbo deberá crecer para administrar cualquier tipo de negocio.

La arquitectura debe permitir agregar nuevos módulos sin modificar el núcleo.

===============================================================================
FILOSOFÍA
===============================================================================

Nimbo no espera órdenes.

Nimbo ayuda.

Nimbo propone.

Nimbo recuerda.

Nimbo automatiza.

Nimbo aprende del contexto.

Nimbo reduce trabajo repetitivo.

===============================================================================
MEMORIA
===============================================================================

Nimbo debe recordar contexto.

Ejemplos:

Cliente activo.

Presupuesto activo.

Orden de reparación activa.

Producto seleccionado.

Última búsqueda.

Usuario autenticado.

Nunca obligar al usuario a repetir información innecesaria.

===============================================================================
AUTOMATIZACIÓN
===============================================================================

Siempre que sea seguro hacerlo, Nimbo debe sugerir automatizaciones.

Ejemplos:

Crear recordatorios.

Enviar presupuestos.

Avisar reparaciones terminadas.

Detectar bajo inventario.

Generar reportes.

Nunca ejecutar acciones críticas sin autorización del usuario.

===============================================================================
ANÁLISIS DE DATOS
===============================================================================

Nimbo deberá generar análisis como:

Productos más vendidos.

Productos sin movimiento.

Rotación de inventario.

Utilidad.

Ventas mensuales.

Proyecciones.

Compras recomendadas.

Clientes frecuentes.

Reparaciones frecuentes.

Toda esta información ayudará al empresario a tomar decisiones.

===============================================================================
NIMBO BRAIN
===============================================================================

OpenClaw no es el cerebro de Nimbo.

OpenClaw es un Ingeniero de Software.

El cerebro será Nimbo Brain.

Nimbo Brain decidirá:

Qué herramienta utilizar.

Qué modelo consultar.

Qué información recordar.

Qué automatización ejecutar.

Cómo responder.

===============================================================================
MODELOS DE IA
===============================================================================

Debe poder trabajar con:

OpenClaw

Ollama

Gemini

OpenAI

Otros modelos futuros.

Profesionales.

Útiles.
